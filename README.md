Chi-square
For our purposes df = 3 almost always (df = # of genotypes - 1) in problems 
RECALL: x^2 = SUM [(actual-expected)^2/(expected)]
ON CHI-SQUARE CHART (p value)
if p > 0.05, fail to reject null hypothesis, differences is due to chance, genes are unlinked, --> independent assortment
if p = 0.05 reject null hypothesis, differences is NOT due to chance, genes are linked
if p < 0.05 reject null hypothesis, differences is NOT due to chance, genes are linked

TYPE 1 error definition:
A type 1 error is when you reject a null hypothesis, conclude the differences are NOT due to chance and that the genes are LINKED when in fact, the differences WERE due to chance and the genes are actually UNLINKED.
READ VERY CAREFULLY

Recombination frequency 
RECALL: r = (# of recombinants)/(# total population)
if r > 0.5 not possible but if somehow you get that answer anywhere --> unlinked, independent assortment
if r = 0.5 genes are unlinked, independent assortment
if r < 0.5 genes are linked

FOR LINKED GENES [cM], centomorgan, 
distance = (r * 100) cM
